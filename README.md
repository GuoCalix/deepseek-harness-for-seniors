# AI for the old

中文 | [English](#english)

## 中文

面向中老年人的本地 DeepSeek 任务工作台。任务描述、候选意图、多轮澄清、结果建议和反馈问题使用实时 DeepSeek API；未连接账号时明确提示登录，固定答案仅在显式测试模式中启用。

### 安装与连接

从 [GitHub Releases](https://github.com/GuoCalix/deepseek-harness-for-seniors/releases) 下载与你的电脑匹配的安装包：

| 电脑 | 文件后缀 |
| --- | --- |
| Apple Silicon Mac（M1/M2/M3/M4 等） | `mac-arm64.dmg` |
| Intel Mac | `mac-x64.dmg` |
| Windows 64 位 | `win-x64.exe` |

macOS 打开 DMG，把应用拖入 Applications；Windows 运行一键 NSIS 安装程序。应用已包含运行环境，无需安装 Node、Python 或命令行工具。不要在 Apple Silicon Mac 上选择 Intel 安装包。

在“账户与充值 → 管理连接”中打开官方账号授权，使用官方页面的微信扫码或手机号登录。成功回调后，账号授权自动用于 DeepSeek 请求。也可以选择“使用已有 API key”，粘贴后自动验证余额并安全保存；无需配置环境变量。账号和 API key 在桌面版由 macOS Keychain / Windows DPAPI 保护，不写入任务、日志或浏览器持久存储。

余额直接读取 DeepSeek：账号模式使用 Harness 的账户钱包接口，API key 模式使用官方 [Get User Balance](https://api-docs.deepseek.com/api/get-user-balance/)。充值余额和赠送余额分开显示，刷新失败保留旧值并明确标记；token 统计只累计本应用调用，不把估算当成真实账单。充值按钮打开官方页面选择金额和支付，返回后刷新余额；本应用不代收款、不伪造支付回调。

**签名状态：**未配置 Developer ID 和 Apple 公证凭据时，macOS 包使用 ad-hoc 签名，Gatekeeper 仍可能提示无法验证开发者。正式免此提示的分发需要维护者提供证书并运行公证流程，不能靠修改应用代码保证消除。Windows 的未签名安装包也可能显示 SmartScreen 提示。不要关闭系统安全保护；核对来源与校验和后使用系统提供的单次打开选项。

### 开发与验证

```bash
git clone --recurse-submodules https://github.com/GuoCalix/deepseek-harness-for-seniors.git
cd deepseek-harness-for-seniors
npm ci
npm run dev
```

需要 Node.js 22.22.2 或更高版本，推荐 Node 22 当前维护版。开发页为 <http://127.0.0.1:4178>。开发服务器的登录凭据只保留在内存，重启需重连；也可从服务进程环境读取 `DEEPSEEK_API_KEY`。安装包不会包含任何密钥。

```bash
npm run check
npm test
npm run build
npm run test:desktop
npm run test:desktop:closed-loop
npm run desktop:mac -- --arm64
npm run desktop:mac -- --x64
npm run desktop:win -- --x64
```

依赖下载可设置 `HTTPS_PROXY=http://127.0.0.1:6268` 和 `HTTP_PROXY=http://127.0.0.1:6268`。官方 API 默认直连；不要关闭 TLS 校验。

## English

A local DeepSeek task workspace for older adults. Intent candidates, multi-round clarification, result suggestions and feedback questions are generated by live DeepSeek API requests. Missing credentials produce an explicit connection error; fixed answers require explicit test mode.

### Install and connect

Download a matching installer from [GitHub Releases](https://github.com/GuoCalix/deepseek-harness-for-seniors/releases):

| Computer | Filename suffix |
| --- | --- |
| Apple Silicon Mac | `mac-arm64.dmg` |
| Intel Mac | `mac-x64.dmg` |
| Windows 64-bit | `win-x64.exe` |

On macOS, open the DMG and drag the app to Applications. On Windows, run the one-click NSIS installer. No separate Node, Python or command-line installation is needed.

Open **Account & billing → Manage connection** and authorize on the official DeepSeek page using WeChat QR or phone sign-in. A successful loopback callback automatically enables account-backed inference. Alternatively, select **Use an existing API key**; the app verifies its balance and stores it securely. Desktop credentials are protected by macOS Keychain / Windows DPAPI and excluded from task files, logs and browser storage.

Account mode queries the Harness wallet endpoints; API-key mode queries the official [Get User Balance](https://api-docs.deepseek.com/api/get-user-balance/) endpoint. Top-up and granted funds remain separate. Failed refreshes are marked stale and never displayed as zero. Token totals describe this app's calls, not an estimated provider bill. Top-up opens the official amount-selection and payment page; return to refresh the balance. This app does not collect money or simulate payment callbacks.

**Signing:** without Developer ID and notarization credentials, macOS packages use ad-hoc signing and may show a Gatekeeper unidentified-developer warning. Formal distribution without that warning requires Apple's signing and notarization process. Unsigned Windows installers may also show SmartScreen warnings. Do not disable OS security; verify the source/checksum and use the OS's per-app opening procedure.

### Verification and remaining acceptance work

v0.1.9 fixes a scope regression when a task is reopened: localized display labels are no longer sent as filesystem paths. Absolute authorized subdirectories, symlinked paths and English/Chinese scope aliases are accepted while the approved-root restriction remains enforced. The v0.1.8 Harness-style DeepSeek v4 Pro agent loop, thinking and guarded local tools remain enabled. The isolated Electron closed-loop test moved two ordinarily named `.dmg` files into temporary Trash with zero renderer errors.

Live PKCE initialization and the official WeChat QR page were verified. Real account-grant inference, account-wallet retrieval and settled payment still require user interaction for acceptance. Protocol fixture tests do not stand in for those checks.

This release repairs the existing Electron application's account, distribution and local execution flows. The design document's Tauri/Rust migration, SQLite event store, complete Word/PDF conversion, cross-platform native permission integration and production-grade recovery remain future work. The implementation explicitly supports the restricted tools and CSV/HTML formats listed above; this release is not full acceptance of the entire design. The original requirements remain intact.
