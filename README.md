# AI for the old

中文 | [English](#english)

## 中文

AI for the old 是一个本地优先的 DeepSeek 任务工作台，面向需要处理文件、材料、表格和文档、但不想面对命令行和复杂提示词的用户。任务路径是：

`描述需求 → DeepSeek 实时生成最多三个意图 → DeepSeek 实时澄清 → 查看执行预览 → 授权范围 → 本地 workspace 执行 → DeepSeek 实时生成结果建议 → 反馈并继续修改`

所有候选意图、澄清问题、执行预览、结果摘要、下一步建议和反馈选项都由服务端实时调用 DeepSeek API 生成，并在服务端做 JSON schema 校验。生产模式未配置 `DEEPSEEK_API_KEY` 时会明确报错，不会静默使用固定候选；固定内容只在自动化测试通过 `AI_OLD_ALLOW_MOCK=true` 时启用。

项目提供大字/高对比度/中英文界面、桌面和下载目录元数据扫描、`input/`、`work/`、`output/`、`logs/` workspace、结构化安全工具白名单、任务历史与版本化反馈。不会执行模型生成的 shell 命令，也不会覆盖原始文件。

### 快速开始

需要 Node.js 22 或更高版本：

```bash
npm ci
DEEPSEEK_API_KEY='sk-...' npm run dev
```

打开 <http://127.0.0.1:4178>。开发 API 仅监听 `127.0.0.1:4179`，Vite 将 `/api` 转发到该地址。依赖下载需要代理时：

```bash
HTTPS_PROXY=http://127.0.0.1:6268 HTTP_PROXY=http://127.0.0.1:6268 npm ci
```

API key 只从本地服务进程环境读取，不接受浏览器请求体中的 key，不写入 localStorage、任务快照、日志或 Git。请使用独立的低额度 key，并在调试完成后按 DeepSeek 控制台策略轮换它。

### 桌面安装包

GitHub Release 工作流会在 macOS 和 Windows runner 上构建真实的一键安装包：macOS 为 `.dmg`，Windows 为 NSIS `.exe`。发布页见 <https://github.com/GuoCalix/deepseek-harness-for-seniors/releases>。

本机打包命令：

```bash
npm run desktop:mac   # macOS .dmg
npm run desktop:win   # Windows .exe（应在 Windows runner 执行）
npm run desktop:dir   # 当前平台目录安装检查
```

安装后仍需让应用进程获得 `DEEPSEEK_API_KEY`。macOS 可从终端启动应用主二进制，Windows 可在设置环境变量后启动应用。安装包不会内置任何密钥。

### 登录、余额与充值边界

二维码只打开 DeepSeek 官方网页登录入口。DeepSeek 公开 API 文档没有把网页扫码会话转换为 API key 的设备/OAuth 接口，也没有公开的客户端余额或充值 API。因此项目不会读取浏览器 cookie、伪造余额或代收充值；账户页面会显示“余额不可从 API 读取”，并引导到官方平台完成账单操作：<https://platform.deepseek.com/>。

## English

AI for the old is a local-first DeepSeek task workspace for people who need help with files, documents, spreadsheets, and everyday computer work without learning shell commands or prompt engineering. The task path is:

`describe the goal → DeepSeek generates up to three intents → DeepSeek clarifies in real time → review the execution preview → approve the access scope → run in a local workspace → DeepSeek generates result suggestions → give feedback and revise`

Candidates, clarification questions, execution previews, result summaries, next-step suggestions, and feedback options are generated by live DeepSeek API calls on the local service and validated against explicit JSON contracts. In production, a missing `DEEPSEEK_API_KEY` fails clearly instead of silently falling back to fixed candidates. Fixed responses are available only to tests that set `AI_OLD_ALLOW_MOCK=true`.

The product includes large text, high contrast, bilingual UI, Desktop/Downloads metadata indexing, `input/`, `work/`, `output/`, and `logs/` workspaces, a structured safe-tool allowlist, task history, and versioned feedback. It never executes model-generated shell commands and does not overwrite source files.

### Quick start

Node.js 22 or newer is required:

```bash
npm ci
DEEPSEEK_API_KEY='sk-...' npm run dev
```

Open <http://127.0.0.1:4178>. The API listens on loopback at `127.0.0.1:4179`, and Vite proxies `/api` there. For dependency installation through the configured proxy:

```bash
HTTPS_PROXY=http://127.0.0.1:6268 HTTP_PROXY=http://127.0.0.1:6268 npm ci
```

The key is read only from the local service environment. It is rejected from browser request bodies and is never stored in localStorage, task snapshots, logs, or Git. Use a low-limit key and rotate it according to DeepSeek's console policy after validation.

### Desktop installers

The GitHub Release workflow builds real one-click installers on native runners: a `.dmg` for macOS and an NSIS `.exe` for Windows. Releases are published at <https://github.com/GuoCalix/deepseek-harness-for-seniors/releases>.

Local packaging commands:

```bash
npm run desktop:mac   # macOS .dmg
npm run desktop:win   # Windows .exe (run on a Windows runner)
npm run desktop:dir   # unpacked installation smoke check
```

The installed application still needs `DEEPSEEK_API_KEY` in its process environment. On macOS, launch the packaged executable from a shell with the variable set; on Windows, set the environment variable before starting the app. No installer contains a credential.

### Login, balance, and recharge boundaries

The QR code opens the official DeepSeek web sign-in page only. DeepSeek's public API documentation does not expose a device/OAuth endpoint that converts a web QR session into an API key, nor a documented client balance or recharge API. This project therefore never reads browser cookies, invents a balance, or handles payments. The account view reports that balance is unavailable through the API and links to the official platform for billing: <https://platform.deepseek.com/>.
