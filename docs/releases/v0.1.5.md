# v0.1.5 — Clarification response fix

## 中文

修复选择候选意图后出现“DeepSeek 返回缺少任务目标”的问题。

原因是 DeepSeek 在需要继续追问时只返回下一个问题是合法的，但旧版服务端错误地要求每个澄清响应都必须包含最终任务目标。现在只有 `ready_to_run` 响应需要完整的任务目标、预计产物、联网说明和确认摘要；`ask_question` 可以只返回一个问题。选择候选项时，应用还会把候选标题、说明和所需文件范围一起传入下一轮实时请求。

本版本沿用 v0.1.4 的三平台安装包构建与安全策略。下载页面会提供 Apple Silicon DMG、Intel DMG、Windows EXE 和 SHA-256 校验文件。

## English

Fixes the “DeepSeek response is missing the task goal” error after selecting an intent candidate.

DeepSeek may legitimately return only the next question when clarification is still needed. The previous validator incorrectly required the final task goal in every clarification response. Only `ready_to_run` now requires the complete goal, expected output, network explanation and summary; `ask_question` may contain only one question. The selected candidate's title, description and required file scope are also included in the next live request.

The v0.1.4 three-platform packaging and security strategy is retained. The release page provides Apple Silicon and Intel DMGs, a Windows EXE and SHA-256 checksums.
