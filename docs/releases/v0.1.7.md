# v0.1.7 — Structured local execution

## 中文

本版本把确认后的 DeepSeek 计划接入受限的本地工具执行器。支持文件列举、元数据和文本读取、复制到任务 workspace、移入可恢复回收站、创建目录、写入文本、Markdown/TXT 转 HTML、生成 CSV 表格和打开任务结果。模型只能返回结构化 JSON；每个动作和路径都要通过白名单、授权目录和 workspace 校验，不执行 shell 或模型生成的任意命令。

执行预览确认后，目录和联网授权一次性记录到任务。执行页提供暂停、继续和停止，执行日志追加写入 workspace/logs；失败任务保留失败原因并可重试。Electron 隔离闭环测试实际把临时 Desktop 的“安装包.dmg”移入临时回收站，候选、澄清、预览、执行、结果和反馈流程均通过，渲染错误为 0。

本版本的 HTML/CSV 转换是无第三方 Office 引擎的基础格式实现。Tauri/Rust、SQLite 事件存储、完整 Word/PDF 转换、跨平台原生权限和生产级崩溃恢复仍是后续工作。发布附件应由 macOS arm64、macOS x64 和 Windows x64 CI 构建并附带 SHA256 校验文件。

## English

This release connects confirmed DeepSeek plans to a restricted local tool executor. It supports file listing, metadata and text reads, copying into the task workspace, recoverable Trash moves, directory creation, text output, Markdown/TXT-to-HTML conversion, CSV spreadsheet creation and restricted result opening. The model may return structured JSON only; every action and path passes the allowlist, approved roots and workspace checks. Shell commands and arbitrary model-generated commands are never executed.

After the execution preview is confirmed, directory and network consent are stored once for the task. The execution view provides pause, resume and cancel; append-only logs are written under workspace/logs, and failed tasks retain a reason and can be retried. The isolated Electron closed-loop test actually moved a temporary Desktop `安装包.dmg` into a temporary Trash; candidate selection, clarification, preview, execution, result and feedback all passed with zero renderer errors.

The HTML/CSV conversions are intentionally basic format implementations without a third-party Office engine. Tauri/Rust, SQLite event storage, complete Word/PDF conversion, native cross-platform permissions and production crash recovery remain future work. Release attachments should be built by the macOS arm64, macOS x64 and Windows x64 CI jobs with SHA256 checksums.
