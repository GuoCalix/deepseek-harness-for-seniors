# v0.1.6 — Complete clarification loop fix

## 中文

修复选择候选后界面仍显示原来三个选项的问题。

当 DeepSeek 需要继续追问时，服务端现在会持久化新的问题并清除上一轮候选；界面直接显示回答输入框。回答后可以继续请求下一轮，直到出现执行前预览。候选标题、说明和文件范围仍会随选择一起发送给 DeepSeek。

本地闭环测试已完成：候选生成、选择、追问、回答、执行预览、执行结果和反馈修改连续完成 5 次实时模型请求，旧候选已清除，渲染错误为 0。三平台发布检查沿用 v0.1.5 流程。

## English

Fixes the clarification screen that kept showing the original three options after a candidate was submitted.

When DeepSeek asks a follow-up question, the server now persists the new question and clears the previous candidate options. The UI presents a direct answer field, and subsequent answers continue the live clarification loop until an execution preview is ready. The selected candidate's title, description and file scope remain part of the live DeepSeek request.

The complete local loop passed: candidate generation, selection, follow-up question, answer, execution preview, result and feedback revision completed through five live model requests, with stale candidates cleared and zero renderer errors. The v0.1.5 three-platform release checks are retained.
