# v0.1.8 — Harness agent loop and installer matching

## 中文

本版本修复“删除桌面上的安装包”找不到普通命名 `.dmg` 文件的问题。安装包任务现在按 `.dmg`、`.pkg`、`.exe`、`.msi`、`.deb`、`.rpm` 和 `.zip` 扩展名识别，不再强制文件名包含“安装”或 `installer`。

执行阶段接入 Harness 风格的 DeepSeek Messages 工具循环：默认使用 `deepseek-v4-pro`，默认启用 `thinking` 和 `high` reasoning effort；模型可以在一次已确认的授权范围内多轮调用本地工具并读取工具结果。工具计划和路径仍经过白名单、授权目录和 workspace 校验，删除只能进入可恢复回收站。新增的 `run_command` 只允许无 shell 的只读诊断命令。

验证：`npm test -- --run` 通过（23 tests）；`npm run check` 通过；`npm run build` 通过；Electron 闭环测试用两个普通名称的 `.dmg` 文件通过，`filesMoved: 2`，渲染错误为 0。

真实 DeepSeek v4 Pro 请求需要已连接的 DeepSeek 官方账号或 API key。当前发布仍不包含完整 Tauri/Rust 迁移、SQLite 事件库、完整 Office/PDF 转换或任意 shell 执行能力。

## English

This release fixes installer matching for “delete the installers on my Desktop”. Installer tasks now match package extensions (`.dmg`, `.pkg`, `.exe`, `.msi`, `.deb`, `.rpm`, `.zip`) without requiring a filename keyword such as “installer”.

Execution now uses a Harness-style DeepSeek Messages tool loop. The default model is `deepseek-v4-pro` with thinking enabled and `high` reasoning effort. The model can call local tools over multiple rounds and inspect their results within the approved scope. Tool names, paths and workspace writes remain validated; deletion only moves files to recoverable Trash. The new `run_command` tool is shell-free and read-only.

Validation: `npm test -- --run` passed (23 tests); `npm run check` passed; `npm run build` passed; the Electron closed loop moved two ordinarily named `.dmg` files with zero renderer errors.
