# v0.1.4 — Account, balance and desktop startup fixes

## 中文

修复打包后白屏、桌面请求失败及端口冲突；增加独立 Apple Silicon 和 Intel 安装包。Keychain 加密改为异步，系统等待授权时不再阻塞应用主线程。

- [Apple Silicon Mac（M1/M2/M3/M4 等）](https://github.com/GuoCalix/deepseek-harness-for-seniors/releases/download/v0.1.4/AI-for-the-old-0.1.4-mac-arm64.dmg)
- [Intel Mac](https://github.com/GuoCalix/deepseek-harness-for-seniors/releases/download/v0.1.4/AI-for-the-old-0.1.4-mac-x64.dmg)
- [Windows 64 位一键安装](https://github.com/GuoCalix/deepseek-harness-for-seniors/releases/download/v0.1.4/AI-for-the-old-0.1.4-win-x64.exe)

Mac 打开 DMG 后拖入 Applications。发布附件包含 `SHA256SUMS.txt`。

登录采用 DeepSeek Harness 的官方 PKCE 浏览器授权流程，使用官方微信二维码或手机号登录。成功回调后自动连接账号授权；已有 API key 可在界面内验证并加密保存。余额直接查询官方接口，充值与赠送余额分开显示；失败时明确标记旧数据。token 统计仅累计本应用请求，充值按钮进入官方支付页面。

三个平台的打包应用均通过实际启动、页面、IPC、任务交互和系统加密验证，渲染错误为 0。四次真实 API key 请求完成候选、澄清、结果和反馈验证，共 1,485 tokens；官方余额查询成功。离线测试中的固定选项只用于自动化测试，生产交互使用实时 API。

当前 Mac 包为 ad-hoc 签名，尚未取得 Developer ID 和 Apple 公证，因此仍可能显示 Gatekeeper 提示；Windows 安装包未签名，也可能显示 SmartScreen 提示。正式签名流程已配置，但需要维护者的证书与公证凭据。不要关闭系统安全保护。

真实微信扫码后的账号授权推理、账号钱包和充值到账尚需用户完成官方确认后验收；已验证授权初始化和官方扫码页。本版本修复现有 Electron 应用，不代表原设计完整验收：Tauri/Rust、完整文件工具、Word/PDF/表格生成、暂停恢复和 SQLite 等仍未完成，当前执行器主要生成元数据索引及 Markdown 报告。

## English

Fixes packaged blank screens, desktop request failures and fixed-port collisions. Ships separate Apple Silicon and Intel installers. Asynchronous Keychain encryption keeps the main process responsive while the OS awaits authorization.

The application now uses DeepSeek Harness's official browser PKCE authorization flow, or a verified API key stored with OS encryption. Official balance queries distinguish topped-up and granted funds and mark stale data after failures. Metering covers this application's calls; top-up opens the official payment page.

Native packaged applications passed launch, rendering, IPC, task interaction and OS encryption checks on Apple Silicon, Intel Mac and Windows, with zero renderer errors. Four live API-key calls validated candidates, clarification, results and feedback using 1,485 tokens; official balance queries succeeded. Deterministic fixture responses are confined to explicit test mode.

macOS packages are ad-hoc signed and **not notarized**; Windows installers are **unsigned**. Gatekeeper/SmartScreen warnings may remain. The signing workflow requires the maintainer's Developer ID and notarization credentials. Do not disable OS security.

Real post-QR account inference, account-wallet retrieval and settled payment remain pending user confirmation. Authorization initialization and the official QR page were verified. This is a repair release for the existing Electron implementation, not full acceptance of the original design: Tauri/Rust, full file tools, Word/PDF/spreadsheet generation, pause/recovery and SQLite remain outstanding. The current executor primarily indexes metadata and writes Markdown reports.
